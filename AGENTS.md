# AGENTS.md — Інструкції для ШІ-агентів

Навчальний Next.js репозиторій курсу «Агентна інженерія та побудова систем з ШІ-агентами».

## Стек

- Node.js >= 22 (v24), Next.js 16 (App Router), TypeScript (strict), Vitest.
- Менеджер пакетів: `npm`.

## Обов'язкові команди перед звітом «готово»

- `npm test` — модульні та інтеграційні тести (Vitest), мають проходити без помилок.
- `npm run typecheck` — сувора перевірка типів TypeScript.
- `npm run lint` — перевірка стилю та правил ESLint.
- Перед звітом агент зобов'язаний виконати всі три команди й надати їхній статус.

## Межі та безпека

- `.env` та `.env.local` агент не читає, не створює і не редагує (секрети належать людині).
- `.agent-log/` не змінювати вручну — каталог ведеться автоматично через hooks.
- `package.json` та `package-lock.json` змінювати лише за прямою згодою користувача.
- `git push`, видалення файлів та деструктивні команди виконувати тільки після підтвердження.
- Тести виконуються локально без зовнішніх мережевих запитів і викликів платних API (використовувати моки).

## Домовленості

- Моделі обираються ролями з `src/models.ts` (`MODELS.cheap`, `MODELS.flagship`), а не рядками.
- Ціни та параметри моделей звіряються за документацією вендорів, а не з пам'яті.
- Якщо тест падає — заборонено підганяти очікування тесту під хибний код. Спершу виявити причину.
- Формат комітів: Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`).
