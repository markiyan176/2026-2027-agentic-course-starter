# Ціна контексту: базова лінія і MCP-сервер

| інструмент | шар / сервер | до | після | як виміряно | навіщо |
|---|---|---|---|---|---|
| Antigravity | базова лінія, свіжа сесія | ~1 850 токенів | — | системний промпт + вбудовані інструменти | базова ініціалізація сесії |
| Antigravity | Context7 після підключення | ~1 850 токенів | ~2 450 токенів (+600 токенів) | завантаження схеми інструментів MCP | визначення інструментів `mcp__context7__*` |
| Antigravity | Context7 після реального виклику | ~2 450 токенів | ~5 120 токенів (+2 670 токенів) | виклик пошуку документації Next.js App Router | актуальні API Next.js 16 і zod 4 замість застарілих / вгаданих |
| OpenCode | Context7 | не вимірюється | відповідь: 4 120 символів (~1 030 токенів) | opencode export, виклик mcp-інструмента | отримання офіційних фрагментів документації |

## Висновок

- **Ціна MCP у контексті**: Підключення MCP-сервера додає фіксовану вартість схеми інструментів (~600 токенів) та динамічну вартість кожної повернутої сторінки документації (~2 500–4 000 токенів). Оскільки відповідь інструмента зберігається в історії повідомлень, вона надсилається моделі у кожному наступному кроці агентного циклу.
- **Рішення щодо Context7**: Сервер залишаємо для задач із дослідження оновлених API Next.js 16/17 та Zod 4. У разі наближення до лімітів контекстного вікна підключаємо документацію лише на етапі планування.
